# Этап 3 — тренажёр и разбор истории

Репозиторий: **birliktuzdyermek-tech/Finance2**. Раздел `/#trainer` продолжает существующее приложение на HTML/CSS/JavaScript и FastAPI. Браузерный анализатор `browser-rules-1.0`, его веса и серверные API не изменены.

## Что работает

- Семь синтетических примеров: давление от имени банка, запрос кода в смешанном RU/KK, «безопасный» счёт, подмена домена, неявная просьба знакомого, обычное уведомление и предупреждение с цитатой.
- До ответа показан только исходный текст с одинаково оформленными выбираемыми словами. Подсказок по разметке или оценке нет; названия вариантов в списке нейтральные.
- Нажатие слова/ссылки отмечает его, повторное нажатие снимает отметку. Tab и Enter/пробел работают. Можно явно выбрать «Не вижу подозрительных фрагментов». Пустой неподтверждённый ответ не принимается.
- После «Открыть разбор» ответ фиксируется. Три отдельные колонки показывают **ответ пользователя**, **реальный результат Qalqan**, **разметку и пояснение автора**. Отображаются несовпадения пользователя с автором и анализатора с автором.
- Кнопка новой попытки сбрасывает только текущий пример. Переключение примера, раздела или языка сохраняет остальные попытки в памяти вкладки. Баллов игрока, рейтинга, процентов точности и оценок реальной защищённости нет.
- «Сохранить разбор в историю» явно сохраняет текущую попытку один раз. Автоматического заполнения истории при просмотре нет. Сохранённую попытку можно открыть после сброса тренажёра: она не изменяется.
- История различает свои проверки, сценарии и тренажёр, поддерживает фильтр вида проверки и понятную кнопку «Открыть разбор». CSV дополнен видом проверки и версией анализатора.
- Для сохранённого шага сценария история содержит последовательность уже просмотренных шагов до выбранного включительно: балл, новые правила, первое достижение порога предупреждения. Перемотка назад исключает будущие шаги. Последующий сброс сценария не меняет сохранённый разбор.
- Сравнение двух записей истории дополнено раскрывающимся точным текстом и подсветкой, версией анализатора и переходом к разбору выбранной записи. Печать/PDF соответствует этой записи и включает её учебный контекст, если он сохранён.
- RU/KK, мобильный экран, клавиатура и проектор. Переключение языка меняет подписи, сохраняя исходные сообщения и отмеченные слова.

## Как устроено сопоставление

`trainer-engine.js` передаёт анализатору только `exercise.text` и `exercise.channel`. Выбор пользователя, ID примера, авторская разметка и пояснение не участвуют в анализе. Отдельные контрольные тесты меняют их, не меняя результат.

Выбор — слова, разделённые пробелами, а ссылка является одним выбираемым фрагментом. Для списка расхождений любое пересечение точного диапазона с таким словом относит слово к соответствующему набору. Это явно подписано в UI. При этом **подсветка самого анализатора остаётся точной**: например, человек отмечает весь URL, Qalqan подсвечивает только проверенную часть домена. Посимвольное рисование произвольного диапазона в этой версии не предусмотрено.

Авторская разметка — учебное суждение, не подтверждение реального мошенничества. В примере с цитатой автор не отметил подозрительных фрагментов, но правила дают 63. В неявной просьбе знакомого автор выделил контекст, а правила дают 0. Оба расхождения сохранены без подгонки результата. Эти примеры — набор разработки, не независимая проверка точности.

## Данные и файлы

| Файл | Назначение |
|---|---|
| `frontend/trainer-data.js` | Неизменяемый каталог `trainer-1.0`, исходные тексты и отдельная RU/KK разметка автора |
| `frontend/trainer-engine.js` | Токены с UTF-16 координатами, проверка выбора, независимый анализ и списки расхождений |
| `frontend/trainer.js` | Выбор, раскрытие разбора, память попыток, явное сохранение и проектор |
| `frontend/learning-view.js` | Безопасный общий вывод ответов/разметки и сохранённого учебного контекста |
| `frontend/local-store.js` | `saveLearning`: анализ текста прежним способом и отдельный неизменяемый снимок контекста |
| `frontend/learning.css` | Адаптивные стили, состояния выбора и печать |
| `tests/trainer.test.cjs`, `tests/trainer_browser.py` | Логика, браузерный сценарий и проверка приватности |

Все данные и действия остаются в памяти вкладки. Нет fetch, localStorage, sessionStorage или отправки результатов из новых модулей. Введённые и учебные строки выводятся текстовыми узлами; HTML не исполняется. Общий лимит истории остаётся 200 записей. Удаление истории или выход из аккаунта очищают также попытки, черновик сравнения и текущий журнал сценария. Перезагрузка очищает всё. Старые отдельные функции входа и архива метрик остаются сетевыми; содержание проверок в них не передаётся.

## Запуск и проверки

Из каталога Finance2 с установленными зависимостями:

```sh
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8773 --no-proxy-headers
```

Открыть `http://127.0.0.1:8773/#trainer`.

```sh
node --test tests/local_analyzer.test.cjs tests/scenarios.test.cjs tests/comparison.test.cjs tests/trainer.test.cjs
python -m unittest discover -s tests -v
```

Браузерные проверки (после установки `tests/requirements.txt` и браузера Playwright):

```powershell
$env:TEST_BASE_URL='http://127.0.0.1:8773'
$env:CHROMIUM_PATH='C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
python -m tests.trainer_browser
python -m tests.scenarios_browser
python -m tests.comparison_browser
python -m tests.browser_smoke
python -m tests.design_browser_smoke
python -m tests.auth_browser_smoke
```

Локально прошли **49 JavaScript-тестов, 43 Python-теста и все 6 перечисленных браузерных наборов**. Проверены семь реальных результатов, независимость трёх источников разметки, сохранение неизменяемой попытки, отсутствие будущих реплик, фильтры, сравнение, выбранная запись в PDF, HTML-безопасность, RU/KK, клавиатура, проектор, ширины 1024/390px, удаление/перезагрузка, отсутствие persistent storage и сетевой передачи при работе офлайн. Проверка входа использует подменённую доставку кода и не отправляет реальные письма. Новые проверки добавлены в CI.

Скриншоты `artifacts/trainer-desktop.png`, `artifacts/trainer-mobile.png` и PDF `artifacts/learning-history.pdf` создаются тестом и не коммитятся.

## Просмотр этапа за 1–2 минуты

Пример 1: отметить «Срочно», «Введите», «код» → открыть три колонки → сохранить → сбросить попытку → открыть сохранённый ответ в истории. Затем пример 7: выбрать отсутствие подозрительных фрагментов → увидеть 63 у анализатора и объяснение ложной тревоги автора. Для истории сценария пройти «От имени банка» до шага 4, вернуться к шагу 2 и сохранить: в истории останутся шаги 1–2 с баллами 0 и 40.
