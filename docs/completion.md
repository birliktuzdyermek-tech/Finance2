# Этап 4: результат, действия и проверка качества

Изменения подготовлены для `birliktuzdyermek-tech/Finance2`, ветка `codex/qalqan-scenarios`, draft PR #6. Публикация на Render — отдельный шаг после просмотра результата. Анализатор остался `browser-rules-1.0`: веса и пороги в этом этапе не менялись.

## Экран результата

- **Кратко** — исходный текст с точными совпадениями, три признака с наибольшими весами, следующий шаг и предупреждение об ограничениях. Кнопка «Ещё признаков» раскрывает остальные.
- **Подробно** — все признаки, конкретные фрагменты и причины, веса, повторные срабатывания с нулевым дополнительным вкладом, домены, версия и ограничения. Оба вида показывают один результат; переключение не пересчитывает балл.
- Предпочтение вида хранится в памяти вкладки. Очистка истории возвращает краткий вид. Печать всегда включает подробности независимо от вида на экране.
- Сохранены RU/KK, точный смешанный текст, клавиатура, мобильные ширины и проектор. Исходный текст остаётся текстом и не становится HTML.

## «Что уже произошло?»

Новая проверка начинает с явно обозначенного варианта «Только получил сообщение». Выбранная человеком ситуация относится к этой записи: открытие другой записи и переключение языка не переносят её автоматически. История и печать открывают ситуацию выбранной проверки. Ничего не записывается в persistent storage и не передаётся серверу.

Низкий балл не отменяет действия после передачи данных или денег. Контекстная строка использует только реальные признаки анализатора; контакты из ввода не превращаются в рекомендации.

### Основания рекомендаций

Проверены 2026-10-07; локальные тексты RU/KK — краткий пересказ, а не цитаты или персональная банковская консультация.

| Ситуация | Основание |
|---|---|
| Получено сообщение | [gov.kz: защита от мошенников](https://www.gov.kz/situations/733/intro?lang=ru) и [АРРФР](https://www.gov.kz/memleket/entities/ardfm/press/news/details/1275708?lang=ru): не передавать секреты, самостоятельно связаться с банком через официальное приложение или номер на карте |
| Открыта ссылка | [NCSC: phishing recovery](https://www.ncsc.gov.uk/section/respond-recover/phishing): отдельно переход, ввод данных и загрузка файла; проверка устройства при загрузке/установке, наблюдение за операциями. Контакты полиции Великобритании не перенесены в интерфейс Казахстана |
| Введены данные | АРРФР: немедленно обратиться в банк, защитить доступ и карту, сохранить доказательства; NCSC: сменить раскрытый пароль, включая повторное использование |
| Переведены деньги | АРРФР: немедленно обратиться в банк и правоохранительные органы, сохранить сведения; gov.kz: 102 / qamqor.gov.kz. Возврат не обещается |

В интерфейсе ссылки на эти источники открываются только по нажатию. Они фиксированы, не содержат пользовательского текста, используют `noopener noreferrer` и `no-referrer`. Qalqan не проверяет владельца сайта или отправителя и не связан с банками.

## Набор разработки браузерных правил

`tests/fixtures/browser-development.json` содержит 20 авторских синтетических случаев. Он предназначен для разработки и разбора ошибок, **не является независимым тестом или оценкой реальной точности**. Авторская метка не передаётся в анализатор. Положительный результат для этого отчёта: балл ≥35.

| Итог | Количество |
|---|---:|
| Предупреждение совпало с авторской меткой (TP) | 8 |
| Отсутствие предупреждения совпало с меткой (TN) | 7 |
| Ложные тревоги (FP) | 2 |
| Пропуски (FN) | 3 |

Сохранённые ошибки:

- `quoted-warning` — пересказ мошеннической фразы в предупреждении: 63, ложная тревога.
- `coupon-code` — код купона вне банковского секрета: 45, ложная тревога.
- `implicit-request` — просьба перевести деньги от непроверенного нового номера: 0, пропуск.
- `mixed-script-obfuscation` — подмена букв другим алфавитом: 0, пропуск.
- `ip-only` — URL с IP: 25, признак есть, но балл ниже порога, пропуск по авторской метке.

Полные входы, фактические результаты, коды правил, версия и SHA-256 доступны в [воспроизводимом отчёте](browser-development-report.json). Скрипт проверяет повторяемость и соответствие каждого фрагмента исходному тексту. Hash анализатора нормализует только переводы строк файла для одинакового результата Windows/Linux. Серверные метрики не включены в этот отчёт.

```bash
node scripts/evaluate_browser_development.cjs
node --test tests/local_analyzer.test.cjs tests/scenarios.test.cjs tests/comparison.test.cjs tests/trainer.test.cjs tests/result_guidance.test.cjs
```

## Браузерные проверки

Установить `tests/requirements.txt` и Playwright Chromium либо указать путь к Edge в `CHROMIUM_PATH`. Запустить приложение, задать `TEST_BASE_URL` (по умолчанию `http://127.0.0.1:8000`).

```bash
python -m tests.result_modes_browser
python -m tests.trainer_browser
python -m tests.scenarios_browser
python -m tests.comparison_browser
python -m tests.browser_smoke
python -m tests.design_browser_smoke
python -m tests.auth_browser_smoke
```

Этап проверяет реальные результаты диалога 0 → 40 → 40 → 85, изменённую копию 40 и обычное сообщение 0; режимы, исходные фрагменты, сохранение ситуации, действия при нулевом балле, подробную печать, RU/KK, HTML, клавиатуру, проектор и 1024/390px. После загрузки проверочные действия выполняются офлайн; разрешены только запросы фиксированной иконки браузера без данных. Авторизация проверяется отдельно с имитацией доставки, без настоящих писем.

Скриншоты и PDF создаются в игнорируемой папке `artifacts/`. [Связный показ на четыре минуты](../presentation/demo-and-qa.md) и `presentation/record_demo.py` используют реальные результаты. Никакие демонстрационные баллы не подставляются в UI.

## Оставшиеся ограничения

Правила не понимают смысл надёжно: цитаты, сложные отрицания, косвенные просьбы, обфускация и неизвестные формулировки дают ошибки. URL проверяется по строке; нет DNS, переходов, репутации, проверки владельца, возраста или содержимого сайта. Балл — сумма признаков с ограничением 100, не вероятность. История живёт только до перезагрузки вкладки; PDF остаётся у пользователя. Независимого внешнего набора и доказательств эффективности на реальных банковских сообщениях нет.
