# Этап 1 — пошаговые сценарии Qalqan

Репозиторий: **birliktuzdyermek-tech/Finance2**. Новый раздел `/#scenarios` использует существующие HTML/CSS/JavaScript, тёмный дизайн и `frontend/analyzer.js`. Серверные API и правила оценки не изменены.

## Что работает

- Семь синтетических диалогов: от имени банка, просьба сообщить код, «безопасный» счёт, подмена домена, срочная просьба знакомого, обычное уведомление, предупреждение с цитатой.
- Запуск с интервалом 2,4 секунды, пауза, следующая/предыдущая реплика, сброс, возврат по уже пройденным шагам.
- Реальный анализ только показанных реплик; итоговый балл, новые правила и изменение относительно предыдущей реплики. Повтор правила не увеличивает вес.
- Подсветка точных совпадений и причины по каждой реплике. Роли участников — учебная подпись, не подтверждённая личность.
- RU/KK, клавиатура, мобильный экран, режим проектора. Переключение интерфейса не переводит текст диалога и не меняет результат.
- «Открыть полное объяснение» сохраняет выбранный префикс в существующей истории вкладки. Его можно открыть и распечатать существующими средствами. Обычное проигрывание само не заполняет общую историю.

На примере «От имени банка» текущий анализатор даёт **0 → 40 → 40 → 85**. Это вычисляемые результаты; этих чисел нет в данных сценария или логике интерфейса. Тесты фиксируют наблюдаемый результат как регрессионное ожидание.

## Файлы и границы данных

| Файл | Назначение |
|---|---|
| `frontend/scenarios-data.js` | Данные каталога `scenarios-1.0`, неизменяемые объекты с RU/KK названиями и пояснениями |
| `frontend/scenario-engine.js` | Причинный снимок выбранного шага и история шагов в памяти |
| `frontend/scenarios.js` | Управление воспроизведением и безопасная отрисовка через текстовые узлы |
| `frontend/scenarios.css` | Адаптивный вид в существующем дизайне |
| `frontend/index.html`, `frontend/app.js`, `frontend/i18n.js` | Навигация, передача в существующий результат, язык и проектор |
| `tests/scenarios.test.cjs`, `tests/scenarios_browser.py` | Логика и браузерная проверка, включая приватность |

В анализатор передаются только тексты уже открытых реплик и канал. Название, описание, роль участника, пояснение автора и будущие реплики не участвуют в оценке. Контрольный тест подменяет метаданные и будущее, сохраняя результат текущего шага.

Каталог загружается как статический JS-файл вместе с приложением, чтобы после первой загрузки сценарии работали без сети. Во время проигрывания, перемотки и открытия результата запросов с содержимым нет. Нет localStorage/sessionStorage, БД или отправки действий. Смена сценария и сброс очищают его журнал; обновление страницы очищает всю сессию. Обе проверки приватности выполняются в браузере офлайн с перехватом запросов.

Новый сценарий добавляется объектом данных: уникальный `id`, `channel`, `title`/`description`/`note` на RU/KK и `turns` со `speaker` (`sender`/`recipient`) и `text`. Не более 20 реплик и 10 000 символов суммарно — пределы текущего анализатора. Переключателей по ID сценария в UI нет. Для детерминированных фиксированных диалогов случайный seed не нужен.

## Проверки

```sh
node --test tests/local_analyzer.test.cjs tests/scenarios.test.cjs
python -m unittest discover -s tests -v
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8773 --no-proxy-headers
# в отдельном терминале после установки tests/requirements.txt и Chromium:
python -m tests.scenarios_browser
```

Другой адрес приложения задаётся через `TEST_BASE_URL`. Установленный Chromium/Edge — через `CHROMIUM_PATH`. Например в PowerShell:

```powershell
$env:TEST_BASE_URL='http://127.0.0.1:8773'
$env:CHROMIUM_PATH='C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
python -m tests.scenarios_browser
python -m tests.browser_smoke
```

Локально прошли **29 JavaScript-тестов**, **43 Python-теста**, новый браузерный сценарий и прежний `browser_smoke`. Проверены все семь сценариев, появление предупреждения, изоляция будущих реплик, повторы, rewind/reset, пауза и уход со страницы, передача выбранного шага в историю, RU/KK, клавиатура, проектор, 390px без горизонтального переполнения, очистка при перезагрузке и отсутствие сетевой передачи. Скриншоты — в игнорируемом `artifacts/`; новые проверки добавлены в CI.

## Ограничения и следующие этапы

Сценарии — авторские примеры разработки, не независимый тест качества. Анализатор не понимает цитирование и сложный контекст надёжно. Предупреждение с цитатой получает 63, хотя автор описывает его как безопасное предупреждение: ложная тревога сохранена и объяснена. Просьба знакомого получает лишь 18; правила не подтверждают личность и могут пропустить смысл. Низкий балл не подтверждает безопасность.

Редактируемая копия «Что изменится?» добавлена на [этапе 2](comparison.md). Тренажёр выбора фрагментов и сохранение последовательности выбранного сценария в разборе истории добавлены на [этапе 3](trainer.md). Новый подробный режим относится к этапу 4. Пояснение автора открывается после последней реплики и явно отделено от результата Qalqan.
