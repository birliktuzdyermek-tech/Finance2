# Qalqan Finance Security
## Проверяйте сообщение до того, как передадите данные или деньги

**Проблема.** Злоумышленник может имитировать банк, создать ощущение срочности и запросить код, CVV или перевод. Пользователю нужен понятный ответ с основаниями и следующим действием.

**Аудитория.** Клиенты банков, студенты и сотрудники поддержки. Первый сценарий — ручная проверка сомнительного сообщения; банковский API-пилот рассматривается следующим этапом.

**Решение.** SMS / WhatsApp / email / URL → правила текста и домена + ML baseline → индекс риска, признаки, рекомендация. Интерфейс включает историю, обзор угроз и PDF-отчёт. Ссылки не открываются; исходные сообщения не сохраняются.

**Ценность и новизна-гипотеза.** Единый понятный процесс для финансовых сценариев RU/KZ/EN, прозрачное разделение эвристик и ML, воспроизводимый эксперимент, объяснение ограничений. Глобальная уникальность не доказана; потребуются сравнение с внешними решениями и пользовательская проверка полезности.

**Технологии и готовность.** FastAPI, character TF-IDF + Logistic Regression, offline URL parsing, SQLite / PostgreSQL, Docker, Render Blueprint. Адаптивный frontend работает без CDN и шага сборки. Система готова для лабораторного демо; самооценка TRL 4. Реальные банки и партнёрства не заявлены.

**Результат эксперимента.** 132 синтетические строки / 44 шаблона, 30 групп train и 14 test. На 42 тестовых строках: Precision 87,5%, Recall 100%, F1 0,933, ROC-AUC 1,000, FPR 14,3%. Это малый коррелированный набор; правила оказались сильнее ML. Тест использован при разработке. Требуется новый независимый слепой тест, прежде чем говорить о банковской точности.

**Внедрение и развитие.** Сначала независимый dataset и разметка, затем ручной пилот в поддержке. Для production: SSO, роли, общий limiter, timed deletion, репутация ссылок, нагрузочные проверки и monitoring drift. Эффект измерять по опасным действиям пользователей, false alarms и времени проверки.

**Бюджет следующего этапа.** Оценочно 120–240 часов. При условной ставке 3 000 ₸/час — 360 000–720 000 ₸ плюс инфраструктура и источники данных. Это плановая оценка, не понесённые расходы.
