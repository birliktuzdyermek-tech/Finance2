# Демо до 5 минут и вопросы жюри

## Связный показ, около четырёх минут

Откройте `/#demo` в локально запущенной ветке `codex/qalqan-scenarios`. Публичная версия Render пока не включает эти этапы; её обновление обсуждается отдельно. Используйте новую вкладку, чтобы начать с пустой истории. Все примеры синтетические, баллы вычисляет текущий браузерный анализатор. Открытие страницы само не создаёт проверки.

| Время | Действие | Что объяснить |
|---|---|---|
| 0:00–0:20 | Демо → «Начать диалог» | Это учебные реплики, анализ локальный |
| 0:20–1:20 | Пройти четыре реплики «От имени банка» | Фактический ряд 0 → 40 → 40 → 85; первое предупреждение на шаге 2; нейтральный ответ не добавляет баллы |
| 1:20–2:20 | «Открыть полное объяснение», «Кратко»/«Подробно», РУС/ҚАЗ; «Ввёл данные» | Точные совпадения, веса правил, версии и ограничения; действия зависят от ситуации, балл не подтверждает подлинность |
| 2:20–3:21 | «Что изменится?»; заменить последнюю реплику на «Проверю через приложение банка.»; сравнить | Реальное изменение 85 → 40: исчез запрос секрета, сохранились срочность и угроза блокировки. Снижение балла не доказывает безопасность; оригинал остаётся 85 |
| 3:21–3:45 | Вернуться к оригиналу, затем `/#demo` → обычное сообщение | 0 у обычного уведомления с финансовыми словами; проверка отправителя не выполнена |
| 3:45–4:05 | История, открыть обычную проверку, предпросмотр PDF | Отчёт выбранной записи, версия анализатора, ограничения; полная печать включает исходный текст |

Автозапись того же маршрута (~4:05, без озвучки):

```powershell
$env:TEST_BASE_URL='http://127.0.0.1:8773'
$env:CHROMIUM_PATH='C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
python -m playwright install ffmpeg
python presentation/record_demo.py
```

Для Chromium вместо Edge выполните `python -m playwright install chromium ffmpeg` и не задавайте `CHROMIUM_PATH`. Файл: `artifacts/Qalqan-stage4-demo.webm`, не включается в Git. Запись использует отдельный пустой контекст и после загрузки работает офлайн. При использовании записи на защите обозначьте её как запись. Данные действий и результаты не подставляются в интерфейс.

## Краткие ответы

- **Где AI?** Обучаемая character TF-IDF + Logistic Regression есть в отдельном серверном API и эксперименте. Текущая форма проверяет сообщения локальными правилами в браузере и не показывает ML-оценку.
- **Почему правила лучше?** Синтетический набор слишком прост и похож на сценарии правил. Это ограничение эксперимента, требующее нового внешнего теста.
- **Какое качество текущих правил?** На новом наборе разработки из 20 авторских случаев: TP 8, TN 7, FP 2, FN 3. Цитата и купон дают ложные тревоги; косвенная просьба, смешение алфавитов и IP ниже порога дают пропуски. Полные случаи сохранены. Архивные серверные метрики относятся к другому эксперименту; независимого теста нет.
- **Что означают 87/100?** Индекс риска, не 87% вероятности. Калибровка не выполнена.
- **Какая новизна?** Продуктовая комбинация финансовых признаков, объяснения, RU/KZ/EN и воспроизводимого evaluation. Глобальный приоритет не заявлен.
- **Проверяется ли возраст домена?** Нет. Текущая URL-проверка offline; WHOIS/репутация предусмотрены следующим этапом.
- **Где данные пользователя?** В текущей веб-форме текст, история и результаты находятся в памяти вкладки и исчезают после перезагрузки; сохранённый пользователем PDF остаётся у него. Прямой вызов старого серверного API передаёт текст серверу, а БД хранит производные признаки и домены. Домены тоже могут быть чувствительными.
- **Есть ли банковские партнёры?** Не подтверждены. Текущий статус — лабораторный MVP.
- **Как измерить эффект?** Независимый corpus, FPR при заданном Recall, показатели по языкам, затем разрешённое исследование решений пользователей до/после.
- **Можно ли блокировать перевод?** На текущей модели нельзя обосновать автоматическую блокировку; рекомендуем проверку человеком.
- **Как масштабировать?** Общий limiter, SSO/роли, pool БД, реестр модели, monitoring и контролируемая интеграция; не добавлять реплики к process-local limiter.
- **Почему frontend без React?** Для MVP достаточно браузерного клиента без CDN и сборки; API остаётся независимым, переход на React возможен по мере развития продукта.
- **Есть ли гарантированная безопасность?** Нет, короткий текст, обфускация, неизвестные кампании и сложные отрицания могут приводить к ошибкам. Ограничения отображены в интерфейсе.

## Перед подачей

Уточнить официальное написание вуза, роли участников, руководителя и контакты; сверить оригинальный DOCX и допуск после 1 октября; добавить URL/видео; уточнить правила лицензии, формат технического приложения и официальную оценку TRL. Эти поля не заполняются вымышленными данными.
