# Dataset card — Qalqan synthetic v1

**Источник:** авторские демонстрационные сообщения из `generate.py`. Внешние корпуса, персональные данные, реальные банковские сообщения и реальные вредоносные ссылки не использованы. Адреса `.example` и `192.0.2.1` предназначены для документации; некоторые официальные домены служат только примерами справочника. Ссылки не открываются.

**Цель:** воспроизводимая проверка pipeline и базовое сравнение правил и ML. Набор не репрезентативен для банковского трафика и не предназначен для измерения коммерческого качества.

44 шаблона × 3 варианта = 132 строки. В шаблонах без суммы варианты совпадают; число строк не равно числу независимых наблюдений. Метки: `0` — обычное/предупреждающее сообщение; `1` — авторский сценарий фишинга. Языки: русский, казахский, английский. Метки задаёт автор, независимой двойной разметки нет.

Фиксированное разделение на уровне шаблонов: train — 30 групп / 90 строк; test — 14 групп / 42 строки. В test есть оба класса в каждом языке. Seed 42 фиксирует обучение; split задан явно до оценки. Группы и точные тексты между train/test не пересекаются, близкие смысловые сценарии могут пересекаться. Эти ограничения не устраняются обычным групповым split.

Колонки: `id`, `group`, `language`, `label`, `split`, `text`, `source`. Набор и код распространяются по лицензии MIT репозитория.

Следующий эксперимент: собрать разрешённые обезличенные сообщения, разметить двумя независимыми аннотаторами, включить бытовые сообщения, легитимные уведомления о блокировке, предупреждения банка, смешанные языки и обфускацию. Делить по кампании/источнику и времени; внешний тест не использовать для настройки порогов.
