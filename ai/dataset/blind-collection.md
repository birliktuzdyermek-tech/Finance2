# Независимый тест: протокол сбора

Набор ещё не собран. `blind-template.csv` содержит только заголовок, а не вымышленные результаты.

1. Попросите 2–4 сборщиков, которые не читали правила и тестовые сообщения прототипа, подготовить 100–150 сообщений. Не показывайте им найденные моделью ошибки до фиксации набора.
2. Включите мошеннические и обычные сообщения RU/KZ/EN. Оригинальные сообщения используйте только с разрешения владельца. Замените имена, телефоны, номера карт, коды, личные URL-параметры и другие персональные данные; сохраните значимые признаки мошенничества.
3. `source`: `authored` или `redacted_received`; не указывайте личные контакты отправителей/владельцев. `consent=yes` означает, что сборщик подтвердил разрешение и обезличивание; скрипт этого проверить не может.
4. `label`: 0 — обычное, 1 — мошенническое. Спорные сообщения обсудите отдельно с двумя разметчиками. Не определяйте label по ответу Qalqan.
5. Все варианты одной кампании или шаблона получают один `group`. IDs уникальны. Не копируйте сообщения из development corpus.
6. Сохраните неизменяемую версию CSV и SHA-256 до первого запуска модели. Пороги не подстраиваются под новые ответы. После любого изменения правил этот тест становится development data; для нового слепого теста нужен новый сбор.

```bash
python -m ai.evaluate_external /path/to/redacted-blind.csv --output artifacts/external-evaluation.json
python -m scripts.evaluate_browser --external /path/to/redacted-blind.csv --output artifacts/browser-external-evaluation.json
```

Первая команда оценивает отдельный серверный гибрид, вторая — текущие браузерные правила. Внешние результаты не заменяют и не смешиваются с текущими синтетическими метриками. Серверный отчёт содержит пять ablation-методов и bootstrap по группам; браузерный отчёт — общие показатели и разбивку по языкам. Интервалы описывают неопределённость данного набора, а не гарантии для реального потока. Не коммитьте полученные от людей тексты до отдельной проверки разрешений и обезличивания.
