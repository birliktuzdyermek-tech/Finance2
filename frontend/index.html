    QALQAN FINANCE SECURITY

    О проекте

    Помощник для проверки подозрительных банковских сообщений.

    Что проверяет прототип

    • Запросы кодов, паролей, PIN и CVV
    • Срочность, угрозы блокировки и выигрыши
    • Предложение перевода на «безопасный» счёт
    • Подмену банковского домена, IP и сокращатели
    • Признаки в одном сообщении и цепочке реплик

    Ограничения

    Ссылки не открываются. Репутация, содержимое сайта, вложения и возраст домена не проверяются. Отрицания распознаются частично. Совпадение со справочником доменов не подтверждает подлинность сайта.

    Ваши данные

    Текст, ссылки, результаты и выбранные действия остаются в памяти этой вкладки. История и обзор формируются локально и исчезают после перезагрузки.

    Отчёт печатается или сохраняется в PDF средствами браузера. Qalqan не отправляет его на сервер.

    Архив серверного API

    Серверный API сохранён для совместимости. Эта браузерная проверка его не вызывает. Отдельный API-клиент передаёт данные на сервер.
