Qalqan API · v0.1

JSON API. История и PDF привязаны к случайному cookie текущей сессии.

Endpoints

МетодПутьНазначение
GET/api/healthМодель и состояние БД
POST/api/analyzeАнализ {content, channel}
GET/api/historyДо 200 проверок сессии
DELETE/api/historyОчистка истории сессии
GET/api/dashboardАгрегаты текущей сессии
GET/api/reports/{id}.pdfPDF сохранённого результата
GET/api/metricsСинтетический эксперимент

content: 3–10 000 символов; channel: sms | whatsapp | email | url. Лимит тела 64 KiB. До 30 изменяющих запросов в минуту на IP в одном процессе. Возвращаемые баллы не являются калиброванной вероятностью.
